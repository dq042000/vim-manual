我的 Neovim 手冊

畫面地圖跳視窗檔案樹上方檔名列 標籤頁分割找檔案程式碼 編輯Claude測試偵錯全部按鍵

畫面地圖：先搞懂你在哪一格

<leader> 就是空格鍵。忘記時按空格停一下，下方會跳出所有可按的鍵（which-key）。

最上方橫條 = 已開的檔案（buffer，不是標籤頁！） Shift+h 上一個檔案　Shift+l 下一個檔案　<leader>bd 關掉這個檔案
左：檔案樹（neo-tree）
打開／關掉：<leader>e
跳去中間：Ctrl+l
看說明：?
中：編輯區
跳去左邊檔案樹：Ctrl+h 或 sh
跳去右邊：Ctrl+l 或 sl
這格滿版 ⇄ 還原：Ctrl+b
右：Claude 側欄
開／關：Alt+r
跳回中間：Ctrl+h
變回 normal mode：連按兩下 Esc

我想要⋯

在左／中／右之間跳來跳去

Ctrl+h Ctrl+l往左／往右一格（在哪一格都能用，最推薦）
Ctrl+j Ctrl+k往下／往上一格
sh sl sj sk同上（你自訂的），但檔案樹裡不能用
Ctrl+w 再按 w依序輪流跳到下一格
Ctrl+w 再按 p跳回上一格待過的地方
為什麼在檔案樹按 sl 沒用？ 因為 s 在檔案樹裡是「用垂直分割打開檔案」，按下去就立刻執行了。 所以從檔案樹回中間，請用 Ctrl+l。

左邊檔案樹裡面的操作

<leader>e打開檔案樹；已開著時再按會關掉（要跳進去用 Ctrl+h）
<leader>E用目前工作目錄開檔案樹
Enter 或 l開檔案／展開資料夾
h收起資料夾
z全部資料夾收起來
s ／ S ／ t用垂直分割／水平分割／新標籤頁開
P預覽檔案（不真的打開）
a ／ A新增檔案／新增資料夾（檔名結尾打 / 也會變資料夾）
r ／ d改名／刪除
y x p複製／剪下／貼上檔案
c ／ m複製到／移動到（打路徑）
Y複製這個檔案的完整路徑
O用系統程式開啟
H顯示／隱藏被收起來的資料夾（node_modules、vendor 等）
/在檔案樹裡搜尋檔名
Backspace ／ .往上一層／把這個資料夾設為根目錄
R重新整理
?顯示檔案樹所有按鍵
q關掉檔案樹

上方檔名列：切換／關閉已開的檔案

Shift+h ／ Shift+l上一個／下一個檔案
[b ／ ]b同上
<leader>,列出已開的檔案，打字挑一個
<leader>bj每個檔名旁出現字母，按字母直接跳
<leader>bb 或 <leader>`切回上一個看過的檔案
<leader>bd關掉目前檔案（視窗保留）
<leader>bo只留目前這個，其他全關
<leader>bl ／ <leader>br關掉左邊／右邊全部
<leader>bp釘選這個檔案（<leader>bP 關掉沒釘選的）
[B ／ ]B把檔名往左／右挪
最常搞混：上方那排是「已開的檔案」，不是標籤頁。 所以按 Tab 不會換檔案，換檔案請用 Shift+h ／ Shift+l。
檔名旁的圖示：黃點 ● 或 [+] = 改過還沒存檔； 紅色圖示 = 這個檔案有錯誤，看內容請見「程式碼」卡片。

標籤頁（整組版面）

Tab ／ Shift+Tab下一個／上一個標籤頁（自訂）
te開新標籤頁，打檔名再按 Enter（自訂）
<leader>Tab Tab開新標籤頁
<leader>Tab ] ／ [下一個／上一個標籤頁
<leader>Tab d關掉這個標籤頁
<leader>Tab o關掉其他標籤頁
gt ／ gTvim 原生的下一個／上一個標籤頁
標籤頁是什麼：一整組視窗排版，不是一個檔案。 例如一個標籤頁放前端、另一個放後端，切過去整個版面一起換。 只有一個標籤頁時，畫面上看不到標籤列。

分割視窗、滿版、調大小

sv 或 <leader>|左右分割（自訂／內建）
ss 或 <leader>-上下分割（自訂／內建）
Ctrl+b目前這格滿版 ⇄ 還原（自訂）
<leader>wd關掉目前這格視窗
Ctrl+← Ctrl+→視窗變窄／變寬
Ctrl+↑ Ctrl+↓視窗變高／變矮
Ctrl+w 再按 =所有視窗平均分配大小
<leader>uz禪模式（只留中間，專心寫）
注意：Ctrl+b 已改成滿版，往上翻頁請用 Ctrl+u。

找檔案、搜內容

<leader>Space用檔名找檔案（像 VSCode 的 Ctrl+P）
<leader>/全專案搜內容（像 VSCode 的 Ctrl+Shift+F）
<leader>fr最近開過的檔案
<leader>sw搜游標所在的字
<leader>sb只在目前檔案搜
<leader>ss跳到這個檔案的函式／類別
<leader>sr全專案搜尋並取代
<leader>sR重開上一次的搜尋結果
<leader>fn開新檔案
搜尋視窗裡（fzf-lua）：Ctrl+j／Ctrl+k 上下選， Enter 開啟，Ctrl+v 分割開、Ctrl+t 丟進 Trouble 清單， F4 開關預覽，Alt+i 顯示被 .gitignore 忽略的檔案，Esc 按一次就關掉。

程式碼：跳定義、看錯誤

gd跳到定義
gr列出誰用到它
gI ／ gy跳到實作／型別定義
Ctrl+o ／ Ctrl+i跳回剛剛的位置／再跳回來
K看說明文件（hover）
<leader>cr重新命名（全專案一起改）
<leader>cacode action（自動修正建議）
<leader>cf格式化
]d ／ [d下一個／上一個問題（錯誤或警告）
]e ／ [e只跳錯誤
<leader>cd顯示這行的錯誤訊息
<leader>xX目前檔案的錯誤清單（Trouble，再按一次關）
<leader>xx所有開著的檔案的錯誤清單（Trouble）
<leader>sd用搜尋視窗列出錯誤，可打字篩選
常用做法：先 ]e 跳到錯誤，再 <leader>cd 看訊息。

編輯、存檔、Git、離開

Ctrl+s存檔
Ctrl+a全選（自訂；原本的「數字 +1」被蓋掉了）
gcc ／ 選取後 gc註解／取消註解
Alt+j ／ Alt+k整行往下／往上搬
s 再打兩個字Flash：畫面上任何地方直接跳過去
u ／ Ctrl+r復原／重做
Esc離開輸入模式，順便清掉搜尋的黃色標記
<leader>gglazygit（Git 介面）
<leader>gb這行是誰改的（blame）；游標所在行尾也會自動顯示作者、日期、commit 訊息
Ctrl+/開／關下方終端機
<leader>qq離開 nvim

Claude Code 側欄

Alt+r開／關 Claude（在側欄裡也能按）
<leader>af跳到 Claude 視窗
Ctrl+h從 Claude 跳回中間
Esc Esc（快速連按）變回 normal mode（單按一下會送給 Claude 當中斷）
<leader>ar ／ <leader>aC接續舊對話／接續上一次對話
<leader>ab把目前檔案丟給 Claude
選取後 <leader>as把選取的程式碼丟給 Claude
<leader>aa ／ <leader>ad接受／拒絕 Claude 的修改

測試與偵錯

<leader>tr跑游標所在的那個測試
<leader>tt ／ <leader>tT跑這個檔案／整個專案的測試
<leader>ts開／關測試清單側欄
<leader>to看測試輸出
<leader>db下中斷點
<leader>dc開始／繼續執行（PHP 選「Listen for Xdebug」）
<leader>dO <leader>di <leader>do下一行／進入函式／跳出函式
<leader>du開／關偵錯畫面
<leader>dt結束偵錯

全忘光時的救命鍵

Space 停一下列出所有 <leader> 開頭的鍵
<leader>sk搜尋所有快速鍵（打中文沒用，打英文如 window、tab）
<leader>?只看目前這個視窗能用的鍵
檔案樹裡按 ?檔案樹專用按鍵
Ctrl+w 再按 Space視窗操作模式，下方會列出能按的鍵

全部快速鍵（從 nvim 自動匯出）
